BETHANY BURT — SUBMISSION WEBSITE

OPEN IT
Unzip the folder, then open index.html. Keep all files together.
Home is populated. Research, About and Side quests say "Coming soon."
The earlier full framework is preserved in the previous downloadable version.

ADD YOUR PHOTOGRAPH
Export your photograph as a JPEG named portrait.jpg and put it in assets/.
Refresh the homepage. It automatically replaces the illustrated placeholder.
Use a portrait-oriented image, ideally around 1000–1500 pixels high.
The frame crops centrally; adjust object-position in styles.css if needed.

PUBLISH ON GITHUB PAGES
1. Create a public repository called YOUR-USERNAME.github.io.
2. Upload the contents of this folder, with index.html at the repository root.
3. In Settings > Pages choose Deploy from a branch, main, /(root), Save.
4. Your website will be https://YOUR-USERNAME.github.io/ once deployment completes.
Changes to the files update the same website address. Keep the GitHub username
and repository name unchanged to retain that address.

EDIT LATER
HTML files contain page text; styles.css controls appearance; site.js controls
the theme switch and automatic photograph display. The research navigation
code remains available for restoring the interactive pages later.
